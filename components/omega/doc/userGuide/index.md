# User Guide

This guide answers *how do I set up and run Omega, and what can I control?*
It is for people running Omega standalone through Polaris, running it as the
ocean component of E3SM, or building and testing it inside E3SM. It is
practical: each model option links to the {ref}`omega-tech-guide` for what it
means, and to the {ref}`omega-dev-guide` for the code behind it.
