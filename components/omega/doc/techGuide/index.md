# Technical Guide

This guide answers *what does the model compute, and why?* It is for
scientists and reviewers, and for developers checking an implementation
against its description. It follows the model from the continuous equations
to their discretization and the parameterizations. Notation stays close to
the variable names in the code, and each page links to the files that
implement it.

Much of this guide is still to be written; pages that have not been written
yet say so.
